# Student Profile Generator

## Overview
Student Profile Generator is a beginner-friendly Python project that collects a student's basic information from the user and displays it in a structured format.

## Features
- Accepts student name
- Accepts age
- Accepts college name
- Accepts branch name
- Accepts CGPA
- Displays the complete student profile

## Technologies Used
- Python

## Concepts Practiced
- Variables
- User Input
- Data Types
- Output Formatting
