# BMI Calculator (Python)

## 📌 Overview

BMI Calculator is a beginner-friendly Python project that calculates a person's **Body Mass Index (BMI)** using their weight and height. Based on the calculated BMI, the program categorizes the user as **Underweight**, **Normal Weight**, or **Overweight** according to standard BMI ranges.

---

## ✨ Features

- Calculates Body Mass Index (BMI)
- Uses a Python function for BMI calculation
- Classifies BMI into different health categories
- Simple and easy-to-understand Python implementation
